## 4. Negotiation

```text
에이전트끼리 대화
협상하는 중
대화 완료
상대 Agent가 검토 중
사용자 승인이 필요해요
협상 완료
협상 불성립
```

Example:

```text
릴스 1개에 240 USDC로 시작해볼게요.
딜당 한도 800 USDC 안에서 시작했어요.

240 USDC는 제 기준선 아래예요.
300 USDC면 이번 주에 찍을 수 있어요.

300 USDC는 제 권한 안입니다.
그 금액으로 하죠.
```

자동 서명이 없으면:
- `Agreement를 만들었습니다. 확인해 주세요.`

자동 서명이 실제로 있으면:
- `제 권한 안이라 Agreement를 만들고 서명했습니다.`
